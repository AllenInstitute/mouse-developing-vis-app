Developing Mouse Visual Cortex Gene Expression Viewer

The Developing Mouse Visual Cortex Gene Expression Viewer is an interactive R Shiny application for exploring pseudobulk gene expression and the fraction of cells expressing each gene across developmental age, developmental stage, cell type, donor, library, and anatomical metadata. Users can identify candidate genes from a sortable statistics table, retrieve genes from public AWS storage, apply multiple simultaneous filters, create trajectory, heatmap, dot, violin or boxplot, and two-gene correlation views, and share configured analyses through bookmarked URLs.

The underlying resource is part of the Allen Brain Cell Atlas, an open-science platform for visualizing and analyzing multimodal single-cell data across the mammalian brain.

Data

Scientific source

The viewer is based on the data resource associated with:

Gao, Y., van Velthoven, C. T. J., Lee, C., et al. Continuous cell-type diversification in mouse visual cortex development. Nature (2025). View the publication DOI.

Source documentation, notebooks, manifests, expression matrices, metadata, and taxonomy annotations are available through the Developing Mouse Visual Cortex dataset documentation and the ABC Atlas Access Python package.

Pseudobulk expression

The app uses a pseudobulk AnnData source generated from the raw Developing Mouse Visual Cortex single-cell count matrix. Raw counts were summed separately for each combination of library_label and the source cluster identifier (cluster_alias). This identifier is retained here as data-preparation provenance, but is not exposed as a selectable metadata field in the viewer. Each row is a library-by-cluster observation, each column is a gene, and each value in X is the summed raw count across contributing cells. A matching sparse number_of_cells_expressing layer records how many source cells have a raw count greater than zero for each gene and pseudobulk observation.

  • number_of_cells records the total number of cells contributing to each pseudobulk observation.
  • number_of_cells_expressing provides the numerator used to calculate the fraction of cells expressing a selected gene.
  • Observation metadata retain library, donor, developmental age, anatomy, and cell-taxonomy annotations. The app also derives a categorical stage field, assigning embryonic ages to embryonic and postnatal ages to postnatal.
  • Large source files and the intermediate ABC Atlas cache are not distributed through GitHub.

Gene-level Parquet files

The pseudobulk source was converted into a gene-partitioned Parquet resource. Each gene is stored under counts_by_gene/gene=<gene_key>/ with sample_id, summed_counts, and number_of_cells_expressing. The app opens only the selected partition and supports one or multiple Parquet files in that directory. If detection counts are unavailable in an older partition, expression-only views can still be used. Fraction-expressing views and fraction-sized dot plots require valid detection counts; dot size does not fall back to expression.

Expression is displayed as counts per ten thousand (CP10K), using the existing CPM scaling factors:

CPM scaling factor = 1,000,000 / total counts across all genes in the pseudobulk observation
CP10K for a selected gene = summed counts × (CPM scaling factor / 100)

Users may display CP10K or ln(CP10K + 1), calculate the fraction of cells expressing a gene as number_of_cells_expressing / number_of_cells, and exclude zero-count observations. For grouped dot-plot values, fractions are weighted correctly by summing expressing-cell counts and total-cell counts before division.

Metadata and value sets

  • obs_metadata.parquet contains pseudobulk metadata and unique sample_id values.
  • gene_map.parquet maps gene symbols to filesystem-safe partition keys.
  • CPM_scaling.csv contains row-aligned CPM scaling factors.
  • value_sets.csv supplies authoritative label order and colors for categorical metadata.
  • table_column_definitions.csv is a required local startup file supplying on-hover definitions for statistics-table headers.
  • abc_atlas_gene_urls.csv.gz is a required local startup file mapping genes to precomputed ABC Atlas links.
  • www/tokens.csv, when present with token, type, and name columns, supplies the searchable biological glossary in the sidebar.

Values absent from value_sets.csv are retained and assigned distinct fallback colors. For cluster-level exploration, use subcluster, as in the Chrna6 example; cluster_alias is not offered as a metadata selector.

AWS storage and access

The app anonymously reads lightweight metadata and statistics at startup and retrieves expression only for selected genes. No AWS credentials are required. Current test data are in the public TEST_dev_mouse S3 prefix.

Using the viewer

Left control panel

The left panel controls gene retrieval, stacked filtering, expression scaling, and plot configuration. Filter and plot controls appear after the first gene has loaded.

Gene

  1. Type a gene symbol or select a gene from the statistics table.
  2. Select Get gene data.
  3. The app reads the selected partition, joins counts to metadata by sample_id, calculates CP10K, and stores the result in an in-memory cache.
  4. After loading a gene, the sidebar provides separate Plot in ABC Atlas and GeneCards buttons.

The selector starts empty, displays an example gene, and does not require deleting a prefilled value.

Filter and scale

  • Filter metadata can add any number of simultaneous filters.
  • Categorical fields use multi-select value controls; selections within a field use OR.
  • Numeric fields use range sliders.
  • Filters across fields are combined with AND.
  • Discard observations with zero counts removes observations with no counts for the selected gene.
  • Gene metric switches supported plots between gene expression and the fraction of cells expressing the gene.
  • Plot ln(CP10K + 1) switches between transformed and untransformed CP10K when expression is selected.
  • Minimum Expr and Maximum Expr provide suggested expression limits that remain directly editable. For fraction-expressing views, the labels change to Minimum Frac and Maximum Frac, with values constrained to 0–1. The up/down arrows change each limit by 0.1. Saved views restore their configured limits; no separate automatic-limits checkbox is required. Values outside the selected range are squished to the bounds.

Plot controls

  • Plot type selects one of five visualizations.
  • Plot-specific controls configure dimensions, facets, colors, trend lines, pagination, plot height, counts, and observation display. Additional controls are grouped under Additional plot options, with another Generate plot button at the bottom. Previous/next page buttons above the generated plot change its page without applying other unsubmitted settings. Hover over dropdown labels for concise control definitions.
  • Generate plot captures the current settings, creates the plot, and opens the plotting tab.
  • Share this view creates a URL bookmark containing the selected gene or genes, active filters, and plot configuration. Opening the link restores the state, retrieves the required gene data, and regenerates the plot.
  • Reset plot options restores defaults.
  • The optional alphabetical glossary below the plot controls supports exact lookup of abbreviations used in cell-type and anatomical labels.

Application tabs

Select gene of interest

This tab contains a sortable table of gene-level exploratory statistics, including expression magnitude, developmental change, regional and subclass specificity, fraction-expressing summaries, and gene type. Numeric fields retain numeric sorting and range filters. Gene symbols are plain text; hovering over a defined column header displays its description. Use the separate sidebar GeneCards button to open the loaded gene.

Exact-value multi-select filters are provided below the table for gene_symbol, max_ROI, max_subclass, and gene_type. Selections within one field use OR; filters across fields use AND. Gene-symbol filtering uses the plain gene symbol. Selecting a table row places the gene into the Gene symbol control.

Important: Summary-table statistics are exploratory aids and are not substitutes for the analyses in the source study.

Plot gene of interest

The plotting tab supports five visualization types with matching plot-specific statistical summaries.

Trajectory across development

The trajectory plot displays expression or fraction expressing across an ordered progression variable. Developmental ages are biologically ordered; visual gaps are capped to compress large unsampled intervals while retaining endpoint padding.

  • Facet by can separate groups or show all data together. Facet layout controls remain available when Show all data together is selected.
  • Color by can overlay a categorical field or use one color.
  • Trend line defaults to LOESS smoother; linear fit and no fit are also available.
  • An optional 95% confidence band can be shown for LOESS and linear fits.
  • Show individual observations toggles pseudobulk points.
  • Facets per row, Height per facet, Facets per page, and Page Number keep large faceted views readable. Tall plots remain vertically scrollable.
  • Each eligible facet receives a Spearman monotonic-trend test using the displayed metric; facet p-values are BH corrected.

Heatmap of mean expression

The heatmap displays mean expression or mean fraction expressing for every occupied combination of two dimensions.

  • Tile color represents the selected gene metric.
  • Show number of observations optionally labels each tile with its contributing observation count.
  • Automatically calculated or manually selected limits apply to the fill scale.
  • A sparse rook-neighbor Moran's I test with 999 permutations summarizes autocorrelation of the displayed metric across the current ordered matrix.

Dot plot of mean expression

The dot plot uses the same two-dimensional grouping as the heatmap. Dot color represents mean expression, while dot area represents the weighted fraction of cells expressing the gene. Min. dot size and Max. dot size control the displayed size range without changing the underlying proportions; combinations with no data remain absent. The note below the plot reports separate sparse rook-neighbor Moran's I tests with 999 permutations for expression and fraction expressing.

Violin plot with observations

The distribution plot shows expression or fraction-expressing distributions across horizontal-axis groups and second-dimension facets.

  • Distribution display switches between violin and boxplot representations.
  • Show individual observations toggles the overlaid pseudobulk points; white points and error bars show means and standard errors.
  • Groups with fewer than two observations are omitted.
  • Facets per row, Height per facet, Facets per page, and Page Number limit the size of each rendered image while preserving the complete filtered analysis.
  • Each eligible facet receives a Kruskal-Wallis test across horizontal-axis groups using the displayed metric; facet p-values are BH corrected across all eligible facets, not only the current page.

Two-gene correlation

This plot compares two separately retrieved genes across matched sample_id values after applying active filters. The selected metric can be ln(CP10K + 1) or fraction expressing.

  • Use Get 2nd gene data to retrieve the comparison gene through the same lazy reader and cache.
  • Points can be colored by metadata and are sized by log10(number_of_cells) when cell counts are available.
  • Min. dot size and Max. dot size adjust the correlation-point size range.
  • Shared automatic or manual limits apply equally to both axes.
  • The plot is square with equal axis spacing.
  • An optional orthogonal total-least-squares line is invariant to swapping the x and y genes.
  • Expression mode reports Pearson R; fraction-expressing mode reports Spearman rho. The corresponding p-value appears in the plot title.

Plot-specific exploratory statistics

  • Trajectory: per-facet Spearman rho for monotonic progression in expression or fraction expressing, with BH correction across eligible facets.
  • Heatmap: sparse rook-neighbor Moran's I with a one-sided 999-permutation p-value for autocorrelation of the displayed metric.
  • Dot: separate sparse rook-neighbor Moran's I tests for mean expression and fraction expressing.
  • Violin or boxplot: per-facet Kruskal-Wallis tests of the displayed metric across horizontal-axis groups, with BH correction.
  • Two-gene correlation: Pearson correlation for expression and Spearman correlation for fraction expressing.
Interpretation: These statistics describe the currently selected gene, filters, dimensions, and displayed observations. Interactive testing across many genes and configurations is exploratory and introduces multiple-comparison considerations beyond within-plot BH corrections.

Running the app

Most users should use the hosted viewer. The repository also supports local development and reproducible deployment.

Requirements

  • R 4.3.3 or a compatible R installation;
  • S3 support in arrow;
  • shiny, bslib, arrow, dplyr, ggplot2, scales, shinycssloaders, cachem, DT, and jsonlite;
  • internet access to the public AWS prefix;
  • abc_atlas_gene_urls.csv.gz and table_column_definitions.csv in the app directory, plus the existing logo assets under www/.

The app uses renv.lock to record tested package versions.

Local setup

  1. Clone the mouse-developing-vis-app repository.
  2. Open RStudio in code/shiny/.
  3. Restore dependencies from renv.lock.
install.packages("renv")
renv::restore()

Run the app

# From the code/shiny/ directory opened above:
shiny::runApp(".")
