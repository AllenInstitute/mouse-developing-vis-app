Developing Mouse Visual Cortex Gene Expression Viewer

The Developing Mouse Visual Cortex Gene Expression Viewer is an interactive R Shiny application for exploring pseudobulk gene expression across developmental age, cell type, donor, library, and anatomical metadata. Users can identify candidate genes from a sortable statistics table, retrieve genes from public AWS storage, apply multiple simultaneous filters, and create trajectory, heatmap, dot, violin, or two-gene correlation plots.

The underlying resource is part of the Allen Brain Cell Atlas, an open-science platform for visualizing and analyzing multimodal single-cell data across the mammalian brain.

Data

Scientific source

The viewer is based on the data resource associated with:

Gao, Y., van Velthoven, C. T. J., Lee, C., et al. Continuous cell-type diversification in mouse visual cortex development. Nature (2025). View the publication DOI.

Source documentation, notebooks, manifests, expression matrices, metadata, and taxonomy annotations are available through the Developing Mouse Visual Cortex dataset documentation and the ABC Atlas Access Python package.

Pseudobulk expression

The app uses a pseudobulk AnnData source generated from the raw Developing Mouse Visual Cortex single-cell count matrix. Raw counts were summed separately for each combination of library_label and cluster_alias. Each row is a library-by-cluster observation, each column is a gene, and each value is the summed raw count across contributing cells.

  • number_of_cells records the number of cells contributing to each pseudobulk observation.
  • Observation metadata retain library, donor, developmental age, anatomy, and cell-taxonomy annotations.
  • Large source files and the intermediate ABC Atlas cache are not distributed through GitHub.

Gene-level Parquet files

The pseudobulk source was converted into a gene-partitioned Parquet resource. Each gene is stored under counts_by_gene/gene=<gene_key>/ with sample_id and summed_counts. The app opens only the selected partition and supports one or multiple Parquet files in that directory.

Expression is displayed as counts per million (CPM):

CPM scaling factor = 1,000,000 / total counts across all genes in the pseudobulk observation
CPM for a selected gene = summed counts × CPM scaling factor

Users may display CPM or ln(CPM + 1) and may exclude zero-count observations.

Metadata and value sets

  • obs_metadata.parquet contains pseudobulk metadata and unique sample_id values.
  • gene_map.parquet maps gene symbols to filesystem-safe partition keys.
  • CPM_scaling.csv contains row-aligned CPM scaling factors.
  • value_sets.csv supplies authoritative label order and colors for categorical metadata.
  • table_column_definitions.csv supplies on-hover definitions for statistics-table headers.

Values absent from value_sets.csv are retained and assigned distinct fallback colors.

AWS storage and access

The app anonymously reads lightweight metadata and statistics at startup and retrieves expression only for selected genes. No AWS credentials are required. Current test data are in the public TEST_dev_mouse S3 prefix.

Using the viewer

Left control panel

The left panel controls gene retrieval, stacked filtering, expression scaling, and plot configuration. Filter and plot controls appear after the first gene has loaded.

Gene

  1. Type a gene symbol or select a gene from the statistics table.
  2. Select Get gene data.
  3. The app reads the selected partition, joins counts to metadata by sample_id, calculates CPM, and stores the result in an in-memory cache.

The selector starts empty, displays an example gene, and does not require deleting a prefilled value.

Filter and scale

  • Filter metadata can add any number of simultaneous filters.
  • Categorical fields use multi-select value controls; selections within a field use OR.
  • Numeric fields use range sliders.
  • Filters across fields are combined with AND.
  • Discard observations with zero counts removes observations with no counts for the selected gene.
  • Plot ln(CPM + 1) switches between transformed and untransformed CPM.
  • Use automatic expression limits can be disabled to enter manual minimum and maximum values. Values outside the selected range are squished to the bounds.

Plot controls

  • Plot type selects one of five visualizations.
  • Plot-specific controls configure dimensions, facets, colors, trend lines, counts, and observation display.
  • Generate plot applies the current settings and opens the plotting tab.
  • Reset plot options restores defaults.

Application tabs

Select gene of interest

This tab contains a sortable table of gene-level exploratory statistics. Numeric fields retain numeric sorting and range filters. Gene symbols link to GeneCards, and hovering over a defined column header displays its description.

Every categorical statistics column except the leading gene-symbol column has a multi-value filter. Selections within one categorical column use OR; filters across columns use AND. Selecting a table row places the gene into the Gene symbol control.

Important: Summary-table statistics are exploratory aids and are not substitutes for the analyses in the source study.

Plot gene of interest

The plotting tab supports five visualization types with matching plot-specific statistical summaries.

Trajectory across development

The trajectory plot displays expression across an ordered progression variable. Developmental ages are biologically ordered; visual gaps are capped to compress large unsampled intervals while retaining endpoint padding.

  • Facet by can separate groups or show all data together.
  • Color by can overlay a categorical field or use one color.
  • Trend line supports LOESS, linear fit, or no fit.
  • Show individual observations toggles pseudobulk points.
  • Each eligible facet receives a Spearman monotonic-trend test; facet p-values are BH corrected.

Heatmap of mean expression

The heatmap displays mean expression for every occupied combination of two dimensions.

  • Tile color represents mean expression.
  • Show number of observations optionally labels each tile with its contributing observation count.
  • Manually selected expression limits apply to the fill scale.
  • A sparse rook-neighbor Moran's I permutation test summarizes autocorrelation across the current ordered matrix.

Dot plot of mean expression

The dot plot uses the same two-dimensional grouping as the heatmap. Dot color and dot area represent mean expression, with selected limits applied to both encodings. A sparse rook-neighbor Moran's I permutation test summarizes matrix autocorrelation.

Violin plot with observations

The violin plot shows expression distributions across horizontal-axis groups and second-dimension facets.

  • Transparent points show observations; white points and error bars show means and standard errors.
  • Groups with fewer than two observations are omitted.
  • Each eligible facet receives a Kruskal-Wallis test across horizontal-axis groups; facet p-values are BH corrected.

Two-gene correlation

This plot compares ln(CPM + 1) for the loaded gene and a separately retrieved comparison gene, joined by sample_id after applying active filters.

  • Use Gene 2nd gene data to retrieve the comparison gene through the same lazy reader and cache.
  • Points can be colored by metadata and are sized by log10(number_of_cells) when cell counts are available.
  • Shared automatic or manual limits apply equally to both axes.
  • The plot is square with equal axis spacing.
  • An optional orthogonal total-least-squares line is invariant to swapping the x and y genes.
  • Pearson R and its p-value appear in the plot title.

Plot-specific exploratory statistics

  • Trajectory: per-facet Spearman rho for monotonic progression, with BH correction across eligible facets.
  • Heatmap and dot: sparse rook-neighbor Moran's I with a one-sided permutation p-value for positive autocorrelation.
  • Violin: per-facet Kruskal-Wallis tests across horizontal-axis groups, with BH correction.
  • Two-gene correlation: Pearson correlation for matched observations.
Interpretation: These statistics describe the currently selected gene, filters, dimensions, and displayed observations. Interactive testing across many genes and configurations is exploratory and introduces multiple-comparison considerations beyond within-plot BH corrections.

Running the app

Most users should use the hosted viewer. The repository also supports local development and reproducible deployment.

Requirements

  • R 4.3.3 or a compatible R installation;
  • S3 support in arrow;
  • shiny, bslib, arrow, dplyr, ggplot2, scales, shinycssloaders, cachem, DT, and jsonlite;
  • internet access to the public AWS prefix.

The app uses renv.lock to record tested package versions.

Local setup

  1. Clone the mouse-aging-app repository.
  2. Open RStudio in code/shiny/.
  3. Restore dependencies from renv.lock.
install.packages("renv")
renv::restore()

Run the app

setwd("code/shiny")
shiny::runApp(".")
